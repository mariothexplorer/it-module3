Източници и сходни сайтове

Тук можете да намерите полезни ресурси и сходни образователни сайтове, които ще ви помогнат да разширите знанията си по уеб дизайн.

Източници:

  • Електронен учебник - Учебник по Модул 3: "Уеб дизайн" по профилирана подготовка по ИТ на издателство Домино ЕООД

  • ChatGPT - ИИ асистент за помощ при уеб разработка

Образователни ресурси за HTML и CSS:

  • W3Schools - Всеобхватен ресурс за HTML, CSS, JavaScript и други уеб технологии
  • Mozilla Developer Network (MDN) - Официална документация и ръководства за уеб технологии
  • Codecademy - Интерактивни курсове по уеб разработка
  • FreeCodeCamp - Безплатни курсове и проекти по уеб разработка

Инструменти за уеб разработка:

  • Visual Studio Code - Популярен текстов редактор за уеб разработка
  • Sublime Text - Мощен текстов редактор
  • WebStorm - IDE за уеб разработка
  • Adobe XD - Инструмент за дизайн на потребителски интерфейси
  • Figma - Облачен инструмент за дизайн

Системи за управление на съдържанието (CMS):

  • WordPress - Най-популярната CMS система
  • Joomla - Мощна CMS платформа
  • Drupal - Гъвкава CMS платформа
  • Wix - Уеб конструктор без кодиране
  • Squarespace - Платформа за уеб дизайн и хостинг

Ресурси за графичен дизайн:

  • Adobe Photoshop - Индустриален стандарт за редактиране на изображения
  • Adobe Illustrator - Инструмент за векторна графика
  • GIMP - Безплатен софтуер за редактиране на изображения
  • Canva - Инструмент за дизайн с готови шаблони
  • Inkscape - Безплатна програма за векторна графика

Хостинг и домейни:

  • HostGator - Популярна хостинг услуга
