Визуално оформяне на уеб сайт с използване на CSS

  1. Стил (Style) Атрибутът style се използва за задаване на визуален стил на HTML елемент, например цвят, размер, шрифт и др. Форматът му е: <tagname style="property: value;">
  2. Cascading Style Sheets (CSS) - език за описание на стилове, който се използва заедно с HTML. Той е създаден за лесно управление на визуалното представяне на съдържанието (шрифтове, размери, цветове, фонове, полета и др.), без да се налага промяна на самите HTML елементи. CSS е мощен инструмент, който с редактиране на един или няколко параметъри може да се промени външния вид на целия сайт.
    Метод Описание Синтаксис Пример
    Inline (Вграден) Чрез атрибута style на конкретен елемент, важи само за него <tag style="свойство: стойност;"> <p style="color: red;">Червен текст</p>
    Internal (Вътрешен) Като блок със стилове, затворени в тага <style> в заглавната част <head>, засяга елементите само от текущата страница <style>
    селектор {
    свойство: стойност;
    }
    </style>    		 <style>
    p {
    color: blue;
    font-size: 14px;
    }
    </style>
    External (Външен) Стиловете са описани в отделен текстов файл с разширение .css. Връзката към него се задава с елемент <link> в заглавната част <head> <link rel="stylesheet" href="style.css"> В style.css файл:
    body {
    font-family: Arial;
    background: #f0f0f0;
    }
  3. Селекторът е шаблон, описващ по определени правила елементите, върху които се прилага правилото. Например селекторът "div" ще съвпадне с всички <div> елементи, а селекторът "div h1" - с елементите <h1>, които са вложени в <div> елемент. Селекторите могат да бъдат няколко, разделени със запетаи. В такъв случай зададените свойства се отнасят за всеки от тях.
  4. Работа с езика Cascading Style Sheets (CSS) - CSS кодът представлява последователност от правила, всяко от които започва със селектори, последвани от блок с дефиниции от свойства и стойности, които им се присвояват.
    Обобщената структура на едно CSS правило е: селектор1, селектор2 { свойство1: стойност; свойство2: стойност; ... }
    Правилата са каскадни, т.е. приложени към даден елемент, те се разпростират върху всичките му подчинени елементи.
  5. Видове селектори в Cascading Style Sheets (CSS):
    Вид селектор Синтаксис Пример Описание
    Селектори за клас .клас
    елемент.клас
    .important { color: red; font-weight: bold; }
    		Избира елементи с определен клас. Може да се комбинира с тип на елемент.
    Групиране на селектори селектор1, селектор2
    h1, h2, h3, .title { color: #2c3e50; border-bottom: 2px solid #3498db; }
    		Прилага същите стилове към няколко различни селектора.
    ID селектори #id
    #header { background: #333; color: white; padding: 20px; }
    		Избира конкретен елемент с уникален идентификатор (id).
    Селектор по тип елемент
    p { line-height: 1.6; margin: 10px 0; }
    		Избира всички елементи от даден тип (p, div, h1 и т.н.)
    Универсален селектор *
    * { margin: 0; padding: 0; box-sizing: border-box; }
    		Избира всички елементи на страницата.
    Селектор по атрибут [атрибут]
    [атрибут=стойност]
    input[type="text"] { border: 1px solid #ccc; padding: 5px; }
    		Избира елементи с определен атрибут или конкретна стойност на атрибут.
    Дъщерен селектор родител > дете
    nav > ul { list-style: none; padding: 0; }
    		Избира директните дъщерни елементи (само едно ниво навлизане).
    Селектор за съсед елемент1 + елемент2
    h1 + p { margin-top: 5px; font-style: italic; }
    		Избира елемент, който е непосредствено след друг елемент.
    Псевдо-класове селектор:псевдоклас
    a:hover { color: red; text-decoration: underline; }
    		Избира елементи в специфично състояние (:hover, :focus, :first-child и т.н.)
