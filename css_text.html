Оформяне на текст с CSS

Свойство Какво прави Пример Визуализация в браузър
color Задава цвета на текста color: #ff0000;
color: red;
color: rgb(255, 0, 0);
color: #ff0000 (червен)
color: #0000ff (син)
color: #008000 (зелен)
text-align Задава хоризонтално подравняване на текста text-align: center;
text-align: left
text-align: center
text-align: right
text-align: justify
font-size Задава размера на шрифта font-size: 16px;
font-size: 12px
font-size: 16px
font-size: 20px
font-size: 24px
font-family Задава шрифта за текста font-family: Arial, sans-serif;
font-family: Arial
font-family: Times New Roman
font-family: Courier New
font-family: Comic Sans MS
font-weight Задава "тегло" на текста font-weight: bold;
font-weight: normal
font-weight: bold
font-weight: lighter
font-weight: 900
text-decoration Задава допълнителен ефект на текста text-decoration: underline;
text-decoration: underline
text-decoration: overline
text-decoration: line-through
text-decoration: none
(blink не се поддържа от повечето браузъри)
text-indent Задава отстъп на първия ред на абзац text-indent: 30px;
Това е пример за текст с отстъп на първия ред. Забележете как първият ред започва по-вдясно от останалите редове в параграфа.
Обикновен параграф без отстъп
letter-spacing Променя разредката между символите letter-spacing: 2px;
letter-spacing: normal
letter-spacing: 3px (широка)
letter-spacing: -1px (тясна)
word-spacing Променя разстоянието между думите word-spacing: 10px;
word-spacing: normal
word-spacing: 10px (широко)
word-spacing: -2px (тясно)
line-height Задава височината на реда (междуредието) line-height: 1.5;
line-height: normal
Това е пример с нормална височина на реда.
line-height: 1.2
Това е пример с тясна височина на реда.
line-height: 2
Това е пример с широка височина на реда.
text-transform Управлява главни и малки букви text-transform: uppercase;
text-transform: none (Обикновен Текст)
text-transform: uppercase (само главни букви)
text-transform: lowercase (САМО МАЛКИ БУКВИ)
text-transform: capitalize (първа буква главна)
