HTML Тагове за Списъци

Таг Описание / Важни Атрибути HTML Пример Визуализация в Браузър
<ul> / <li> **<ul>** създава **неномериран (точкован)** списък (Unordered List). Всеки елемент в списъка се дефинира с **<li>** (List Item). <ul>
  <li>Ябълки</li>
  <li>Банани</li>
</ul>
  • Ябълки
  • Банани
<ol> / <li> Създава **номериран (подреден)** списък (Ordered List). Елементите също се дефинират с **<li>**.
Важни: **`type`** (стил на номерацията), **`start`** (начална стойност). 		<ol type="A" start="3">
  <li>Първа стъпка (C)</li>
  <li>Втора стъпка (D)</li>
</ol>
  1. Първа стъпка (C)
  2. Втора стъпка (D)
<dl>, <dt>, <dd> **<dl>** (Definition List) е за списъци с термини и дефиниции. **<dt>** е терминът, **<dd>** е дефиницията. <dl>
  <dt>HTML</dt>
  <dd>- Маркиращ език.</dd>
  <dt>CSS</dt>
  <dd>- Листове със стилове.</dd>
</dl>
HTML
- Език за маркиране.
CSS
- Стилове.
